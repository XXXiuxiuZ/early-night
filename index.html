    Reminders on iPhone

    Open the app automatically with Shortcuts:

    1. Open the Shortcuts app, tap Automation, then New Automation.
    2. Choose Time of Day and pick your wind-down time, repeating daily.
    3. Select Run Immediately so it doesn’t ask each time.
    4. Add the action Open URL with this app’s link (or Open App if it’s on your Home Screen).

    Tip: pair it with iPhone’s own Sleep Focus (Settings › Focus › Sleep) so notifications quiet down once you’re in bed.
